追跡: [issue #114](https://github.com/mkakh/mhcard-map/issues/114)。期限: **2026-11-18 16:25 JST**。

- 基準: `c2da2f8c17f016ae6e8cba9c0327cb0ae6a651f4`、1313カード、1887位置ターゲット（本体1313・配布窓口572・英語版2）。
- 第1群で宮城県Bに既存データから欠けていた平日・休日の2窓口を追加したため、台帳は**1889ターゲット**。長与町の#116では休日窓口が旧図書館から管理事務所へ置換され、旧キーを削除・新キーを登録（母数の増減なし）。今後の追加・削除・置換も台帳の母数・経緯を明示して調整する。
- `distribution-pin-ledger-2026-10.jsonl` は1行1対象。キーは `location:<cardId>` または `distributionPlaces:<cardId>:<placeId>`／英語版も同様。毎行、カードID、対象種別・ID、現行施設名と住所、座標、判定、判定した場合は閲覧日・カード別公式URL・施設座標根拠を記録する。
- `pending` は**未個別確認**。自動走査が済んだだけでは `confirmed` にしない。過去の手動補正済み地点も今回は pending から再確認する。
- `corrected_pending_deploy` は自治体等のカード案内と施設地点を個別に照合し、修正PRに載せたが未公開。`corrected` はPRマージと本番データの実値確認まで済んだもの。`confirmed` は変更不要と個別の一次情報で判断したもの。`unresolved` は個別照合を試みたが根拠不足・相反情報で判断できず、既存pinを維持したもの。保留も実施件数と未解決件数に分ける。
- 名称だけの検索結果、GKPの一覧、地図の表示中心、カード印刷の蓋の座標を配布施設のpinとして代用しない。複数曜日・建物・休止・移転予定を別対象として扱う。施設の代表地点は入口の実測値と呼ばない。
- 日次作業ではデータのhead SHAと台帳の各キーを再照合し、変化した住所・配布先・座標は以前の判定を引き継がず再検証する。他人の作業や通常の3日ごと更新は上書きしない。
